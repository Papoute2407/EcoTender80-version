# EcoTender80 : versions publiées

Ce dépôt contient seulement les versions publiées d'EcoTender80 (veille des appels d'offres du
bâtiment et prospection d'architectes), pas son code.

## Installer EcoTender80 sur un poste

1. Ouvrir l'onglet *Releases*, à droite, et prendre la dernière version.
2. Télécharger **EcoTender80-Setup-<version>.exe**, puis double-cliquer dessus.
3. Suivre l'assistant : aucun droit administrateur, rien d'autre à installer.

Si Windows affiche « Windows a protégé votre ordinateur », cliquer sur « Informations
complémentaires », puis « Exécuter quand même ».

## Mises à jour

Les postes où EcoTender80 est installé regardent à chaque ouverture la dernière version publiée
ici et proposent de l'installer, d'un clic. Chaque fichier publié est accompagné de son empreinte
SHA-256 (.sha256), vérifiée avant l'installation.
