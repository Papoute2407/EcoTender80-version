# EcoTender80 : versions publiées

Ce dépôt contient seulement les versions publiées d'EcoTender80 (veille des appels d'offres du
bâtiment et prospection d'architectes), pas son code.

Les postes où EcoTender80 est installé regardent à chaque ouverture la dernière version publiée
ici (onglet *Releases*) et proposent de l'installer. Chaque version contient le paquet
`EcoTender80-<version>.zip` et son empreinte SHA-256 `EcoTender80-<version>.zip.sha256`, vérifiée
avant l'installation.

Première installation sur un poste : télécharger le ZIP de la dernière version, le décompresser,
puis double-cliquer sur « Installer EcoTender80.bat ».
